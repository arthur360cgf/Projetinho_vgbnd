# \# Auth Service - Microsserviço de Autenticação OAuth2 \& JWT

# 

# Microsserviço desenvolvido em \*\*Java com Spring Boot\*\* para centralizar o fluxo de autenticação via OAuth2 (Google), emissão de tokens próprios (Access Token e Refresh Token) e gestão de utilizadores com controlo de papéis (USER / ADMIN).

# 

# \---

# 

# \## Tecnologias Utilizadas

# 

# \* \*\*Java 23\*\*

# \* \*\*Spring Boot 3.3.5\*\*

# \* \*\*Spring Security \& OAuth2 Client\*\*

# \* \*\*JJWT (Java JSON Web Token)\*\*

# \* \*\*Spring Data JPA \& H2 Database\*\* (com migração planeada para PostgreSQL)

# \* \*\*Docker \& Docker Compose\*\* (para o ambiente de base de dados)

# \* \*\*Spring Dotenv\*\* (para gestão segura de variáveis de ambiente)

# 

# \---

#
